How to get your history onto the phone

Android keeps Chrome's history inside Chrome's private storage, so no app can read it without root. Google Takeout gives you the same history as a file:
  1. Open takeout.google.com, click Deselect all, tick Chrome (all Chrome data, including Verlauf / History).
  2. Create the export, then download the ZIP when Google e-mails you.
  3. Tap Import above and pick the ZIP, or Share / Open with this app from your file manager.
A History database file copied from a computer (%LOCALAPPDATA%\Google\Chrome\User Data\Default\History) also works and contains the most metadata.

What can and cannot be recorded

Chrome stores no Wi-Fi strength, IP address, GPS position or person's name with a visit, so those can never be recovered for past visits. This app measures them truthfully now: when a report is created, and each time you open a link from a report (Wi-Fi RSSI in dBm, SSID/BSSID, link speed, cell signal, IP addresses, GPS position with accuracy and fix time, battery). Each record is hash-chained so later changes are detectable.
